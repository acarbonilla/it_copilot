# MVP requirements baseline

## Source and status

This baseline records the technology direction and scope supplied by the Product Owner in the IC-001 task specification dated 2026-10-26. It is not a claim that the product features are implemented.

## Approved technology direction

- Next.js with TypeScript
- Tailwind CSS and shadcn/ui
- Django and Django REST Framework
- MySQL
- A dedicated Django-managed document-processing worker using a database-backed job queue
- Docker Compose for local development
- Git and GitHub for version control

## Planned MVP capability areas

- Web user experience
- Django API and MySQL persistence
- Authentication and role permissions
- Document management and asynchronous document processing
- Secure credential handling
- Copilot retrieval and OpenAI integration

Only repository setup is delivered by IC-001. Detailed behavior and acceptance criteria for the capability areas require later approved task specifications.
